# Machine Learning Projects 🧠

Welcome to my **Machine Learning Projects** repository! This repository contains machine learning projects I developed to practice data preprocessing, exploratory data analysis, model training, and prediction using Python.

## 📂 Projects

### 1. ❤️ Heart Disease Prediction

**Objective:** Build a machine learning model to predict the likelihood of heart disease based on patient health information.

**Technologies Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

**Files:**
- `Heart_Disease_prediction.ipynb` — Notebook containing the analysis and model development.
- `heart-disease-data.ipynb` — Additional notebook related to the heart disease project.
- `heart.csv` — Dataset used for the project.
- `heart_disease_model.pkl` — Saved machine learning model.

**Key Learning Areas:**
- Loading and exploring datasets
- Data preprocessing
- Training and evaluating machine learning models
- Making predictions using a trained model

## 🛠️ Installation and Setup

### Prerequisites
- Python 3.10 or later
- pip
- Jupyter Notebook

### Step 1: Clone the repository

```bash
git clone https://github.com/JaspreetSingh1805/Machine-Learning-Projects.git
```

### Step 2: Navigate to the project directory

```bash
cd Machine-Learning-Projects
```

### Step 3: Create and activate a virtual environment

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### Step 4: Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### Step 5: Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the relevant notebook to explore the code and run the analysis.
